# 알려진 이슈 (알고 둔 것)

코드 리뷰에서 확인했지만 실제 플레이 영향이 없거나 비용 대비 이득이 작아 고치지 않기로 한 항목이다. 리뷰에서 다시 나와도 새 문제로 다루지 않는다. 사용자가 이슈 기록은 공유 문서가 아니라 이 파일에만 남기길 원한다.

- 재장전 타이밍 경계: 노티파이가 몽타주 끝에서 서버 조기 종료 여유(`ServerEndSlack`) 안에 있거나 없으면 그 여유가 사라진다. 노티파이~끝 간격이 RTT보다 짧으면 끝날 때 탄약 복제가 아직 안 와서 사격 재개가 안 되고, R을 다시 누르면 클라만 재장전한다(서버는 거부, 롤백 없음).
- 서버 `ServerSetAiming`은 재장전 중에도 true를 받는다. 조작 클라만 해당하고 사격은 `ServerFire`가 막는다.
- 조준 여부가 SavedMove/압축 플래그에 없어 `IsSprinting`이 실시간 `bIsAiming`을 읽는다. 달리다 조준하는 순간 위치 보정이 생길 수 있다(테스트에서는 안 나옴).
- 데디 서버는 사격·재장전 몽타주를 재생하지 않아 총구 위치가 클라와 1~3cm 다르다. 모서리에 걸친 사격만 판정이 갈릴 수 있다. 서버 본 갱신(`AlwaysTickPoseAndRefreshBones`) 비용은 2인이라 무시한다.
- `ChoosePlayerStart`의 시체 제외 코드는 리스폰이 없어져 쓰이지 않는다. `StartReload`는 노티파이 목록을 여러 번 훑고, 노티파이가 없으면 매번 경고를 찍는다.
- 지연 보상(lag compensation) 없음. 보류.
- 부위 판정(`GetHitZone`)은 서버 본 위치를 쓴다. 데디 서버는 사격·재장전 몽타주를 재생하지 않아 상체 본이 클라 화면과 조금 다르고, 부위 경계에 걸친 탄은 판정이 갈릴 수 있다(총구 위치 오차와 같은 원인).
- 피 이펙트는 사격자 화면에서 로컬 판정으로 먼저 재생한다. 서버 판정과 다르면 사격자 화면에만 피가 보이고 데미지는 들어가지 않는다(탄착 연출과 같은 예측 방식).
- 의도한 동작: 모든 맵의 BlockingVolume이 총알을 통과시킨다(`InvisibleWall` 전역 설정). 경기 종료 화면은 "승리"/"패배"만 표시한다(재시작 안내 없음). 재장전 중 달리기는 막지 않는다. 총구→조준 지점 경로에 걸린 상대는 크로스헤어 밖이어도 맞는다(실제 탄도 기준, 코너 피킹 방지와 같은 검사). 연사 중 탄이 떨어지면 빈 격발 몽타주가 마지막 사격 몽타주를 덮어쓴다. 탄이 없을 때 좌클릭을 누른 채 조준하면(재장전 직후 탄약 복제가 늦은 경우 포함) 빈 격발이 한 번 나온다.
- 리뷰 오탐: "클라에서 `Super::FellOutOfWorld`가 폰을 숨긴다"는 틀리다. `AActor::FellOutOfWorld`는 권한이 있거나 `ROLE_None`일 때만 동작하고, CMC의 KillZ 검사도 `ROLE_Authority`에서만 돈다.
